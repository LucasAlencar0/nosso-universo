# Nosso universo

Um coração em 3D feito de "eu te amo" em vários idiomas, com música gerada no navegador, chuva de palavras e fotos que se revelam ao toque.

- `laura.html`: a animação (fonte principal).
- `index.html`: a página do site, gerada com `python build.py`.
- `fotos/`: as fotos (1.jpg, 2.jpg…), que aparecem dentro do coração.
- `serve.py`: abre a animação localmente com `python serve.py`.
